# 知识库维护指南

本文档说明如何管理 RAG 系统的向量知识库（`data/rag_db/`），包括全量重建、增量添加、删除、查看等操作。

---

## 一、知识库结构

```
data/
├── docs/              # 原始 .md 文档（唯一数据源）
│   ├── 员工手册.md
│   └── 产品FAQ.md
└── rag_db/            # Chroma 向量库（由程序自动生成）
```

**原则**：`data/docs/` 是唯一可信源，`rag_db/` 是它的向量投影。修改以 `.md` 文件为准。

---

## 二、快速操作速查

| 目的 | 命令 |
|---|---|
| 首次建库或全量重建 | `python -m app.rag` |
| 新增单个文档到索引 | `python -m app.rag data/docs/新文档.md` |
| 查看索引里有哪些文档 | `GET /api/docs` |
| 运行时增量添加 | `POST /api/docs/add` |
| 运行时删除某文档 | `POST /api/docs/delete` |

---

## 三、详细操作

### 3.1 全量重建

```bash
python -m app.rag
```

会删除 `data/rag_db/` 目录，重新加载 `data/docs/*.md`，切分 → embedding → 写入。适合：

- 首次部署
- 改动了切分参数、换了 embedding 模型
- 批量增删文档后想清掉历史残留

### 3.2 增量添加（推荐日常使用）

把 `.md` 文件放进 `data/docs/`，然后：

```bash
python -m app.rag data/docs/产品FAQ.md
```

**幂等**：如果该文件已在索引中，会先删除旧 chunk 再写入，不会重复。

等价 HTTP API（服务运行中时）：

```bash
curl -X POST http://127.0.0.1:8000/api/docs/add ^
     -H "Content-Type: application/json" ^
     -d "{\"path\": \"data/docs/产品FAQ.md\"}"
```

### 3.3 增量删除

```bash
python -c "from app import rag; rag.delete_document('产品FAQ.md')"
```

或 HTTP：

```bash
curl -X POST http://127.0.0.1:8000/api/docs/delete ^
     -H "Content-Type: application/json" ^
     -d "{\"source\": \"产品FAQ.md\"}"
```

### 3.4 查看当前索引

```bash
python -c "from app import rag; print(rag.list_documents())"
```

或 HTTP：

```bash
curl http://127.0.0.1:8000/api/docs
```

返回示例：

```json
[
  {"source": "员工手册.md", "chunks": 12},
  {"source": "产品FAQ.md", "chunks": 4}
]
```

---

## 四、API 端点一览

| 方法 | 端点 | 请求体 | 说明 |
|---|---|---|---|
| GET | `/api/docs` | — | 列出索引中所有文档及 chunk 数 |
| POST | `/api/reindex` | — | 全量重建索引（清空旧数据） |
| POST | `/api/docs/add` | `{"path": "data/docs/xxx.md"}` | 增量添加单个 `.md` 文件 |
| POST | `/api/docs/delete` | `{"source": "xxx.md"}` | 按 source 删除该文档所有 chunk |

所有写操作（`reindex` / `add` / `delete`）会自动清空 agent 单例缓存，下一次聊天请求会拿到最新的 retriever。

---

## 五、Python API

```python
from app import rag

# 全量重建
rag.build_index()

# 增量添加
rag.add_document("data/docs/新文档.md")

# 删除
rag.delete_document("新文档.md")

# 列表
for d in rag.list_documents():
    print(d["source"], d["chunks"])

# 取检索器（业务代码用）
retriever = rag.get_retriever()
docs = retriever.invoke("怎么重置密码")
```

---

## 六、注意事项

1. **目前只支持 `.md` 文件**。如需支持 `.txt` / `.docx` / `.pdf`，在 `add_document` 和 `build_index` 里加对应 loader 即可。
2. **重复添加同一文件安全**：`add_document` 内部先按 `source` 删旧 chunk 再写入。
3. **运行中修改即时生效**：通过 API 增删改后，下一条聊天请求就能检索到新内容。但命令行操作需确保没有同进程内的 agent 单例缓存未清理（命令行执行不受影响）。
4. **Chroma 持久化在 Windows 上**：如果遇到 `RustBindingsAPI` 相关报错，删除 `data/rag_db/` 后重建即可。
